🎯 IMPORTANT: In PowerShell, always use .\ before .bat files!

┌──────────────────────────────────────────────────────────────────────────┐
│ STEP 1: Setup Database (Creates Test Users)                             │
└──────────────────────────────────────────────────────────────────────────┘

.\SETUP_DATABASE.bat


┌──────────────────────────────────────────────────────────────────────────┐
│ STEP 2: Start Server (Run in first terminal)                            │
└──────────────────────────────────────────────────────────────────────────┘

.\RUN_SERVER.bat


┌──────────────────────────────────────────────────────────────────────────┐
│ STEP 3: Start Client (Run in second terminal)                           │
└──────────────────────────────────────────────────────────────────────────┘

.\RUN_CLIENT.bat


╔══════════════════════════════════════════════════════════════════════════╗
║                      ALTERNATIVE: MAVEN COMMANDS                         ║
║                  (No .\ needed - works in any shell)                     ║
╚══════════════════════════════════════════════════════════════════════════╝

Setup Database:
mvn exec:java "-Dexec.mainClass=com.lfp.util.DatabaseSetup"

Start Server:
mvn exec:java "-Dexec.mainClass=com.lfp.server.LFPServer"

Start Client:
mvn exec:java "-Dexec.mainClass=com.lfp.client.LFPClientApp"
